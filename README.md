# lorenzocallegari.it

Sito personale di Lorenzo Callegari, ospitato su GitHub Pages (dominio: lorenzocallegari.it).

HTML statico, nessun build: ogni pagina è un file `index.html` nella sua cartella.

- `assets/lc-global.css`: CSS del brand book v1.0 (classi `.lc-*`, contenitore `<div class="lc">`)
- `assets/site.css`: header, menu, footer e font ospitati in locale (nessun cookie, nessuna chiamata a Google Fonts)
- `CNAME`, `robots.txt`, `sitemap.xml`: dominio e indicizzazione
